# Session-dan-filter-codeigniter-4

## Deskripsi

Project ini merupakan implementasi **session dan filter pada CodeIgniter 4**.

## Fitur

* Login menggunakan session
* Proteksi halaman menggunakan filter
* Manajemen akses user

## Teknologi

* PHP 8+
* CodeIgniter 4
* MySQL

## Cara Menjalankan

1. Install dependency:

   ```
   composer install
   ```
2. Copy file env:

   ```
   cp env .env
   ```
3. Atur database di file `.env`
4. Jalankan server:

   ```
   php spark serve
   ```
